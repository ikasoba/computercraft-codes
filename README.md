ComputerCraft 用のツールやライブラリ

# [car](./car)

Tar ライクなアーカイブファイルフォーマット、コマンドラインでのツールも含んでおり、圧縮機能はついていない

# [eximager](./eximager)

ディレクトリ内容を自己展開する Lua スクリプトへ変換するツール

変換ツールも単一の Lua スクリプトなので eximager をすぐ利用できます

# [cmd](./cmod)

相対的なモジュール読み込みを可能とする require の薄いラッパー

# [kdb](./kdb)

KV 型データベース実装、更新時にファイルの全体更新を必要としない構造を目指して開発中、未完
